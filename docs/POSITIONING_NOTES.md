This is not a machine learning project. It is a practical AI workflow design and governance project. The point was to make a general-purpose AI useful and reliable inside a narrow, rule-heavy domain.

## Plain-English explanation

I built a system around AI so it could act less like a chatbot and more like a controlled assistant. The project collects structured information, tracks progress, validates outputs, and turns session data into useful coaching feedback.
